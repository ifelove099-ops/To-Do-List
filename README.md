 Styled To-Do List

A simple styled to-do list built with HTML and CSS. The project organizes tasks into categories with checkboxes and provides useful links for each category.

 Features

* Main unordered list with the `todo-list` class
* Categorized tasks:

  * Fashion
  * Beauty
  * Gadgets
* Checkbox for each main task
* Nested lists for related items
* Links for each sub-item
* Custom link states:

  * Default
  * Visited
  * Hover
  * Focus
  * Active
* Custom background colors
* Centered and styled main content area

 Technologies Used

* HTML5
* CSS3
